Exercise: Student Factory & Management System

Objective

Write a class with a method that instantiates a new Student object, populates its attributes, and returns a reference to that object so the caller can interact with it.

Instructions

    Create a Student Class:
        Fields: String name, int id, and double gpa.
        Include a constructor and a displayInfo() method to print the student's details.
    Create a StudentFactory Class:
        Write a method named createStudent(String name, int id, double gpa) that:
            Instantiates a new Student object using new.
            Performs a basic validation check (e.g., if GPA is outside 0.0 to 4.0, default it to 0.0).
            Returns the reference to the newly created Student object.
    In the main Method:
        Call createStudent(...) to build two student objects.
        Store the returned references in local variables.
        Call displayInfo() on those references to prove the objects were successfully created and returned.
