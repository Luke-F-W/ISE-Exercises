Student Exercise: 1-Byte Playing Card Deck

Objective

Build a program that stores an entire 52-card deck in an array of 52 char variables (1 byte per card), shuffles/draws a random 5-card hand without duplicates, and decodes each byte using a union and bitfields.

Memory Layout of a Card (1 Byte = 8 Bits)

Each card is packed into a single unsigned char:

Bits 7–6 (2 bits)
	

Bits 5–2 (4 bits)
	

Bits 1–0 (2 bits)

Unused (set to 0)
	

Rank / Number (1 to 13)
	

Suit (0 to 3)

(Note: On standard little-endian systems like x86/ARM, bitfields declared first occupy the lowest bits—bits 0–1—moving upward toward bit 7.)

    Suit Encoding (2 bits): 0 = Hearts, 1 = Diamonds, 2 = Clubs, 3 = Spades
    Rank Encoding (4 bits): 1 = Ace, 2–10 = Number cards, 11 = Jack, 12 = Queen, 13 = King
